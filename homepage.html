About this project

This is the first project I built entirely on my own using HTML, CSS, and JavaScript, no frameworks, no tutorials to follow step by step, just me figuring things out. The goal was to put my front-end skills to the test and build something I would actually use every day.

The homepage serves as my personal browser start page. It has a grid of quick-access link cards organised by category (development tools, social media, school, entertainment), so I can open anything I need in one click instead of typing URLs every time.

The QR code generator was a fun addition, I use it regularly to share links from my laptop to my phone without needing a messenger app. Type a URL, press generate, scan with your phone. That's it.

The project is hosted on homepage.timolr.nl on Etheron Servers, meaning it's always available in any browser on any device. I've kept updating it since I first built it, adding new links and tweaking the design as my front-end skills improved.

Features

Everything the homepage can do

Quick-access Links

A categorised grid of link cards for the sites I use most. Each card shows a favicon and label. Clicking opens the site in a new tab. Categories include dev tools, school platforms, social media, and entertainment.

QR Code Generator

Type or paste any URL into the input field and click Generate. A QR code appears instantly, rendered entirely client-side using a JavaScript library. Scan it with your phone to open the link immediately.

Responsive Design

The layout adapts from a multi-column desktop grid down to a single-column mobile view. Touch targets are appropriately sized and the page is usable on any screen size without horizontal scrolling.

Custom Styling

Entirely hand-written CSS with custom properties for theming. Hover animations on link cards, smooth transitions, a subtle gradient background, and consistent spacing throughout make the page pleasant to use.

Hosted server

Deployed on Etheron Servers, just like this portfolio website. Easy manageble. I did this, so the site was accecible from any of my devices. If it's my phone, tablet, PC, laptop or even my smart watch, it's possible.

Continuously Updated

I keep the homepage up to date as my daily needs change, new links, layout tweaks, and small features get added regularly. It has grown from a weekend project into a tool I genuinely rely on.

Tech Stack

Kept intentionally simple, no frameworks

HTML5

Structure

Semantic markup for the page structure: sections, nav, article elements, and ARIA attributes for accessibility.

CSS3

Styling & Layout

Custom properties, CSS Grid, Flexbox, media queries, and keyframe animations, written by hand without any preprocessor.

JavaScript

Interactivity

Vanilla ES6+ for all dynamic behaviour: QR code generation, DOM manipulation, event listeners, and local state management.

QR Code Library

Client-side QR

A lightweight JavaScript library renders QR codes entirely in the browser using canvas, no server request, no API key, instant output.

Git

Version Control

Complete change history with descriptive commits. Tagging stable versions before bigger redesigns made it easy to roll back if something broke.

Challenges & Learnings

Challenges I faced

  • Making the QR generator work entirely client-side, understanding canvas rendering and how QR encoding works under the hood.
  • Getting a consistent layout across different browsers and screen sizes without a CSS reset framework.

What I learned

  • CSS Grid and Flexbox in depth, when to use each and how to combine them for complex layouts.
  • How to integrate a third-party JavaScript library without a package manager, reading docs and loading scripts manually.
  • The value of building something you actually use, daily use reveals friction points that you'd never catch in a one-off demo.
  • Deploying and maintaining a live public project, the discipline of keeping it working as you iterate.
  • Responsive design without Bootstrap, understanding breakpoints, fluid typography, and touch-friendly interactions natively.
