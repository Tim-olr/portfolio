About this project

Planfond is a full-stack web application built by a team of five students at Scalda Vlissingen. The goal was to create a practical planning tool for our school that real staff and students could use to manage rooms, lockers, and resources.

The application features an interactive floor-plan map where rooms are placed visually. Users can click on a room to see its availability and make a reservation. Lockers work similarly, a student can browse available lockers and reserve one. An inventory module lets staff track equipment and supplies per room.

We followed an Agile SCRUM process throughout the project: daily stand-ups, sprint planning, retrospectives, and a product backlog in Jira. My personal contributions covered the room reservation flow, the interactive map rendering, and parts of the admin panel.

The back end is built with Java, using Hibernate as the ORM layer for database operations and Struts2 as the MVC framework. Views are rendered through JSP templates and the data is persisted in a MySQL database.

Key highlights

  • Interactive SVG floor-plan map with clickable rooms
  • Role-based access: admin vs. regular user
  • Conflict detection, prevents double-booking of rooms or lockers
  • Hibernate ORM handling complex entity relationships
  • Complete SCRUM workflow over multiple sprints
  • Admin panel for full CRUD on users, rooms, and inventory

Features

Everything the application can do

User Authentication

Secure login and registration with hashed passwords. Session management keeps users logged in, and role-based permissions restrict what regular users and admins can access.

Interactive Floor Map

A visual floor plan of the school building rendered in the browser. Rooms are positioned on the map and colour-coded by availability. Clicking a room opens a panel to view details and create a reservation.

Room Reservations

Users can reserve rooms for specific dates and times. The system automatically detects conflicts and prevents double-booking. Reservations can be viewed, edited, or cancelled from the user dashboard.

Locker Management

Students can browse a list of lockers, filter by floor or size, and claim an available one. The reservation is tied to their account. Staff can view all locker assignments and free up lockers as needed.

Inventory System

Each room has an inventory list of equipment and supplies (projectors, chairs, whiteboards, etc.). Staff can add, update, and remove items. The system shows which resources are available and in which rooms.

Admin Panel

Admins have access to a dedicated management panel for full CRUD operations on users, rooms, lockers, reservations, and inventory. They can promote users to admin, override reservations, and generate usage reports.

Tech Stack

The technologies powering Planfond

Java

Back-end logic

Core language for all server-side business logic, data models, and application flow.

Hibernate

ORM / Persistence

Maps Java objects to MySQL tables, handles entity relationships, and manages database sessions and transactions.

Struts2

MVC Framework

Provides the MVC structure: routing HTTP requests to Java actions, binding form data, and forwarding to JSP views.

MySQL

Database

Relational database storing users, rooms, lockers, reservations, and inventory with foreign-key constraints and indexes.

JSP

View Layer

JavaServer Pages used as the templating engine for generating dynamic HTML pages from server-side data.

Git / GitHub

Version Control

Branching strategy with feature branches and pull requests to manage parallel work across 5 developers.

Challenges & Learnings

Challenges we faced

  • Configuring Hibernate session factories and connection pooling for the first time, required deep reading of the documentation.
  • Building the interactive floor-map with vanilla JavaScript: placing rooms accurately and handling click events on dynamic elements.
  • Coordinating Git branches across 5 developers without merge conflicts, we learned good branch hygiene the hard way.
  • Designing the database schema to handle overlapping reservation time-windows efficiently.

What I learned

  • Enterprise Java patterns: the MVC pattern via Struts2, ORM via Hibernate, and how they work together.
  • How to run a real SCRUM sprint: writing user stories, estimating story points, and reviewing a demo with stakeholders.
  • Relational database design, normalisation, foreign keys, and writing efficient HQL queries.
  • Teamwork under pressure: splitting features, reviewing each other's code, and communicating blockers early.
  • Deploying a Java web application to a local and remote Tomcat server and troubleshooting classpath and dependency issues.
