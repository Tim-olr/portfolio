About this project

PlanTim started because I wanted one place for my agenda, my to-dos and my notes, without handing all of it to a big platform. So I built it myself: a planner with a clean, flat layout in the spirit of the new Outlook and Trello, over a themed photo background.

The front end is plain HTML, CSS and vanilla JavaScript: no framework, no build step and no dependencies. A tiny optional back end (PHP or Node.js) adds cross-device sync. Everything is encrypted in the browser before it is sent, so the server only ever stores data it cannot read.

It is installable as an app on desktop and phone, works offline, and sends reminders through push notifications. I use it every day.

Want to try it? The demo runs entirely in your browser with sample data. Nothing is saved: refresh the page and it starts over.

Key highlights

  • Zero-knowledge encryption with AES-GCM and PBKDF2
  • Natural-language quick add: “Lunch with Sam tomorrow 1pm #social”
  • Drag to move, resize or duplicate events
  • Boards and calendar linked both ways
  • Cross-device sync, offline support and push reminders
  • Zero dependencies, plain vanilla JavaScript

Features

Everything the application can do

Calendar Views

Day, 3-day, week, work week, month and agenda views with a mini calendar and an upcoming list. Repeating events, reminders, checklists and coloured labels, all with keyboard shortcuts.

Natural-language Quick Add

Type a sentence and PlanTim works out the date, time, duration, label, reminder and repeat rule, with a live preview. It can also drop a card straight onto a board.

Boards

Trello-style boards with lists and cards, due dates, repeating routines and filters. Drag a card onto the calendar to plan it; moving it to Done marks the event as done too.

Notes

Obsidian-style markdown notes in a folder tree, with [[links]] between notes, backlinks, to-do checkboxes and an edit and read mode.

Encrypted Sync

My password never leaves my device. It is turned into an encryption key and a separate login key, so the server only holds ciphertext. A recovery key lets me reset a forgotten password without losing any data.

Installable App

A progressive web app with a service worker: I have it installed on my phone and desktop, it works offline, sends me push reminders and a morning digest, and can import .ics calendars.

Tech Stack

The technologies powering PlanTim

Vanilla JavaScript

Front end

The whole app: rendering, drag and drop, the natural-language parser and recurrence rules, without any framework.

HTML & CSS

Layout & themes

A flat, responsive layout with photo themes, light and dark mode and a custom theme editor.

Web Crypto API

Encryption

PBKDF2-SHA256 key derivation and AES-GCM encryption, all in the browser.

PHP / Node.js

Sync server

A small back end that stores the encrypted blob, handles sessions and sends Web Push notifications. Runs on any PHP host or as a Node.js server.

Service Worker

PWA

Offline caching, installability, scheduled reminders and push notifications.

Challenges & Learnings

Challenges I faced

  • Designing encryption where the server never sees the password or the data, while still allowing a safe password reset.
  • Repeating events: expanding rules, skipping single occurrences and detaching one instance when it is dragged.
  • Parsing natural language in any word order without a library.
  • Keeping devices in sync, including edits made while offline.

What I learned

  • Applied cryptography with the Web Crypto API: key derivation, authenticated encryption and key wrapping.
  • How far you can get with plain JavaScript, and how to keep a large codebase readable without a framework.
  • Service workers, Web Push and what it takes to make a web app feel like a native app.
  • Building something I use every day, which makes every rough edge obvious.
